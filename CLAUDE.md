# Project context
## What this is
The internal admin dashboard for Harbor & Pine Supply (a fictional outdoor-gear wholesaler; made-up data). Admins see and manage customer accounts.
## Commands
Build/test: npm test
## Conventions
JavaScript (ES modules), Node's built-in test runner. Code in src/, tests in test/, plans in docs/plans/, threat models in docs/threat-models/.
## Do not touch
- data/ (customer records; a person changes them)
- .env files and anything under secrets/
## Before you finish
Run the tests, then summarize what changed and why.
